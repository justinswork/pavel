# Cellar & Co.

An example store: a product catalog, a cart, and checkout. Some products (wine, beer, a kitchen knife) are marked 21+, but nothing checks the buyer's age yet.

## Run

From the repository root:

```bash
corepack pnpm install
corepack pnpm dev
```

Then open `http://localhost:3000`. Set `PORT` to use a different port.
